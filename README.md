# Қазақстанның мемлекеттік рәміздері — 3D Виртуалды Мұражайы

Мектеп оқушыларына арналған Қазақстан Республикасының Мемлекеттік рәміздерін (Ту, Елтаңба, Әнұран) таныстыратын заманауи интерактивті 3D виртуалды көрме веб-қосымшасы. Оқушылар сыныпта немесе үйде смартфон камерасымен QR-кодты сканерлеп, бірден 3D мұражай залына ене алады.

---

## 🚀 Негізгі ерекшеліктері мен технологиялық стек

- **Стек**: React 19 + Vite + Three.js + `@react-three/fiber` + `@react-three/drei` + `lucide-react`
- **Мобильді құрылғыларға бейімделген (Mobile-First)**:
  - 1 саусақпен кеңістікті еркін бұру (`OrbitControls`, damping қосулы, масштаб шектелген).
  - Жәдігерді (Ту, Елтаңба, Әнұран) басқанда камера автоматты түрде жақындап, төменнен ақпараттық панель ашылады.
  - Төменгі навигация батырмалары: **«Алдыңғы»**, **«Бастапқы бет»**, **«Келесі»**.
  - **Үлкен батырмалар**: Телефон экранында басқанға ыңғайлы 44px+ өлшемді түймелер.
  - Жоғары сапалы көрініс пен портрет/альбомдық режимдерді толық қолдау.
- **Жоғары өнімділік**:
  - Low-poly 3D модельдер мен архитектура.
  - Графикалық жүктемені азайту үшін пиксель қатынасы шектелген (`dpr={[1, 2]}`).
  - Жеңілдетілген текстуралар (1024px-ден төмен).
  - `@react-three/drei` жүктеу индикаторы (`<Loader />`).
- **Сенімділік және қателерден қорғаныс (Fail-Safe)**:
  - Сурет файлы жоқ болса немесе жүктелмей қалса, жүйе құламайды: динамикалық Canvas/SVG арқылы жәдігердің аты жазылған әдемі ұлттық плакат автоматты түрде қойылады.
  - WebGL қолдамайтын ескі телефондар үшін қате ұстаушы (`CanvasErrorBoundary`) жұмыс істеп, барлық ақпаратты 2D ыңғайлы карточкалар тізімі түрінде ұсынады. Сондай-ақ кез келген уақытта «Тізім» түймесі арқылы 2D режимге ауысуға болады.

## 🛠️ Жергілікті ортада іске қосу (Local Development)

### 1. Тәуелділіктерді орнату:
```bash
npm install
```

### 2. Әзірлеуші серверін қосу:
```bash
npm run dev
```
Сервер қосылған соң терминалда көрсетілген сілтемені (мысалы, `http://localhost:5173`) браузерде ашыңыз. Телефоннан тексеру үшін бір жергілікті Wi-Fi желісінде болып, `npm run dev -- --host` арқылы берілген IP адресті енгізуге болады.

### 3. Өндірістік нұсқаны жинақтау (Production Build):
```bash
npm run build
```
Дайын жинақ `dist/` папкасына шығарылады.

## 🖼️ Суреттерді ауыстыру немесе жаңарту

Жәдігерлердің суреттері `public/images/` қалтасында орналасқан:
- `public/images/flag.jpg` — Мемлекеттік Ту
- `public/images/coat-of-arms.jpg` — Мемлекеттік Елтаңба
- `public/images/anthem.jpg` — Мемлекеттік Әнұран

**Суреттерге қойылатын талаптар**:
1. Форматы: `.jpg` немесе `.png`.
2. Өлшемі: телефондар жылдам ашуы үшін ені мен биіктігі **1024px** көлемінде болғаны дұрыс (көлемі 100-500 КБ шамасында).
3. Егер файлдарды кездейсоқ өшіріп алсаңыз да, бағдарлама бұзылмайды: алтын жақтаудың ішінде арнайы дайындалған ресми плакат автоматты түрде пайда болады.

## 🌐 Vercel-ге тегін жариялау (Deploy to Vercel)

Бұл жоба Vercel-дің тегін тарифтік жоспарына (Hobby tier) 100% сәйкес келеді (бэкендсіз, серверсіз, тек статикалық SPA).

### 1-әдіс: GitHub + Vercel Dashboard (Ең оңайы)
1. Кодты өз GitHub репозиторийіңізге жүктеңіз:
   ```bash
   git init
   git add .
   git commit -m "feat: initial kazakhstan 3d symbols museum"
   git remote add origin <РЕПОЗИТОРИЙ_СІЛТЕМЕСІ>
   git push -u origin main
   ```
2. [Vercel.com](https://vercel.com) сайтына кіріп, **"Add New Project"** батырмасын басыңыз.
3. GitHub репозиторийіңізді таңдаңыз.
4. Vercel параметрлерін автоматты түрде таниды:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. **"Deploy"** батырмасын басыңыз. 30 секундтан соң сайт әлемге ашық сілтемемен (мысалы, `https://kz-symbols-museum.vercel.app`) дайын болады!

### 2-әдіс: Vercel CLI арқылы
```bash
npm install -g vercel
vercel
```
Сұрақтарға `Enter` басу арқылы келіссеңіз, сайт автоматты түрде жинақталып жарияланады.
