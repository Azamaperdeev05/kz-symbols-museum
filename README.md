# Қазақстанның мемлекеттік рәміздері — 3D Виртуалды Мұражайы
### Республика күніне арналған виртуалды көрме

Мектеп оқушыларына арналған Қазақстан Республикасының Мемлекеттік рәміздерін (Ту, Елтаңба, Мемлекеттік Гимн) таныстыратын заманауи интерактивті 3D виртуалды көрме веб-қосымшасы. Оқушылар сыныпта немесе үйде смартфон камерасымен QR-кодты сканерлеп, бірден 3D мұражай залына ене алады.

---

## 🚀 Негізгі ерекшеліктері мен технологиялық стек

- **Стек**: React 19 + Vite + Three.js + `@react-three/fiber` + `@react-three/drei` + `lucide-react`
- **Мобильді құрылғыларға бейімделген (Mobile-First)**:
  - 1 саусақпен кеңістікті еркін бұру (`OrbitControls`, damping қосулы, масштаб шектелген).
  - Жәдігерді (Ту, Елтаңба, Әнұран) басқанда камера бірқалыпты ұшып жақындайды және төменнен ақпараттық панель ашылады.
  - Төменгі навигация батырмалары: **«Алдыңғы»**, **«Бастапқы бет»**, **«Келесі»**.
  - **Үлкен батырмалар**: Телефон экранында басқанға ыңғайлы 44px+ өлшемді түймелер.
  - Портрет және альбомдық (landscape) режимдерді толық қолдайды.
- **Жәдігерлер мен деректер (Ресми дереккөз: akorda.kz)**:
  1. **Ту (1992)** — Авторы: Шәкен Ниязбеков. Сурет: `/images/flag.jpg`
  2. **Елтаңба (1992)** — Авторы: Жандарбек Мәлібеков, Шот-Аман Уәлиханов (сәулетшілер). Сурет: `/images/coat-of-arms.jpg`
  3. **Мемлекеттік Гимн (Әнұран) (2006, ән – 1956)**:
     - Музыкасы – Шәмші Қалдаяқов, сөзі – Жұмекен Нәжімеденов (мәтінін өңдеген – Н. Назарбаев).
     - **Фотосуретсіз стильдендірілген плакетка**: 3D және 2D форматта көк-алтын түсті, нота белгісі бар арнайы сәнді тақта (stylized plaque).
     - **Аудио ойнатқыш**: `/audio/anthem.mp4` файлын ойнату/тоқтату (Play/Pause) батырмасымен (автоматты ойнатусыз / no autoplay).
     - **Қосымша ресми сілтеме**: «Нота (PDF)» -> `https://akorda.kz/audio/Anthem_Score.pdf`.
     - Әр панельде міндетті түрде **«Дереккөз: akorda.kz»** көрсетілген.
- **Жоғары өнімділік**:
  - Low-poly 3D модельдер, `dpr={[1, 2]}` шектеуі, Drei `<Loader />`.
- **Қателерден қорғаныс (Fail-Safe & Fallback)**:
  - Егер сурет немесе аудио файлы жоқ болса немесе жүктелмей қалса, жүйе құламайды: динамикалық Canvas/SVG арқылы жәдігер атауы бар бейтарап плакат қойылады.
  - WebGL қолдамайтын ескі телефондар үшін қате ұстаушы (`CanvasErrorBoundary`) жұмыс істеп, барлық ақпаратты 2D карточкалар тізімі түрінде ұсынады.

## 🛠️ Жергілікті ортада іске қосу (Local Development)

### 1. Тәуелділіктерді орнату:
```bash
npm install
```

### 2. Әзірлеуші серверін қосу:
```bash
npm run dev
```
Сервер қосылған соң терминалда көрсетілген сілтемені (мысалы, `http://localhost:5173`) браузерде ашыңыз. Телефоннан тексеру үшін:
```bash
npm run dev -- --host
```

### 3. Өндірістік нұсқаны жинақтау (Production Build):
```bash
npm run build
```
Дайын жинақ `dist/` папкасына шығарылады (Vercel-ге дәл осы папка жіберіледі).

## 🌐 Vercel-ге тегін жариялау (Deploy to Vercel)

Бұл жоба Vercel-дің тегін тарифтік жоспарына (Hobby tier) 100% сәйкес келеді.

### 1-әдіс: GitHub + Vercel
1. Кодты GitHub репозиторийіңізге жіберіңіз:
   ```bash
   git add .
   git commit -m "feat: update exhibits content, anthem audio, and Republic Day theme"
   git push origin main
   ```
2. [Vercel.com](https://vercel.com) сайтында **"Add New Project"** -> GitHub репозиторийіңізді таңдаңыз.
3. Баптаулар:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. **"Deploy"** батырмасын басыңыз. 30 секундта сайт әлемге ашық сілтемемен дайын болады.
